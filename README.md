## 📌 Giới thiệu

Repository này được tạo ra để lưu trữ **bài tập, thực hành và các dự án** trong quá trình học môn **Machine Learning**.

Mục tiêu của repository là xây dựng kiến thức Machine Learning theo hướng:

> **Theory → Mathematics → Implementation → Experiment → Evaluation**

Các thuật toán được tìm hiểu trước bằng cách **tự cài đặt từ đầu (From Scratch)**, sau đó sử dụng **Scikit-learn** để đối chiếu và đánh giá kết quả.
